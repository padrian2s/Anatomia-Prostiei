# Anatomia Prostiei

Interactive exploration of cognitive biases and IQ dilution in social contexts.

## Overview

A web application that examines how cognitive biases manifest in groups and how collective intelligence can be affected by social dynamics. Features interactive visualizations and multiple exploratory pages.

## Contents

- `index.html` - Main entry point
- `pages/` - Additional exploratory pages
- `css/` - Stylesheets
- `js/` - JavaScript logic

## Usage

Open `index.html` in a browser to start exploring the interactive content.
